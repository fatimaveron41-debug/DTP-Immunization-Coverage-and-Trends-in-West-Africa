# DTP Immunization Coverage and Dropout Trends in West Africa

A Power BI capstone dashboard exploring DTP1 and DTP3 immunization coverage, changes over time, and dropout patterns across West African countries.

## Interactive dashboard

[View the Power BI dashboard](https://app.powerbi.com/groups/me/reports/bdb2ab6a-57d1-4ff1-a6e6-93d518d8ddb3/4254acb044b447d65e16?experience=power-bi)

This Power BI workspace link may require sign-in and permission from the report owner.

## Project objectives

- Compare first-dose (DTP1) and third-dose (DTP3) coverage across countries.
- Explore coverage trends over time.
- Compare dropout indicators across countries.
- Inspect country-year observations using interactive filters.

## Dashboard features

- Summary cards for median DTP1 coverage, median DTP3 coverage, and median dropout.
- Country comparisons of DTP1 and DTP3 coverage.
- A time-series chart of DTP1 and DTP3 coverage.
- A country comparison of median dropout.
- Country and year slicers.
- A detail table containing country, year, DTP1, DTP3, dropout, and red-alert observations.

## How to explore

Open the interactive report link above with an authorized Power BI account, or download the PBIX file and open it in Power BI Desktop. Select a country and year to explore the report's coverage and dropout indicators.

## Data provenance and interpretation

The dashboard subtitle attributes the data to WHO/UNICEF estimates and labels the period 2015–2025. The original source dataset, release date, and year range should be confirmed against the source export before treating this label as verified provenance.

The report uses median aggregations in its coverage and dropout visuals. These summaries should not be interpreted as population-weighted regional coverage. The underlying dropout calculation and red-alert criteria are not documented here because their definitions have not yet been verified.
